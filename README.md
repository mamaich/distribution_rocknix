# AURKNIX для AISLPC RG52 Mini ревизии B

Форк [AveyondFly/distribution_rocknix](https://github.com/AveyondFly/distribution_rocknix)
(AURKNIX), который сам является форком
[ROCKNIX](https://github.com/ROCKNIX/distribution) — неизменяемого дистрибутива
Linux для карманных игровых консолей.

Здесь собирается образ под конкретную плату: **AISLPC RG52 Mini ревизии B** на
RK3562. От ревизии A она отличается микросхемой Wi-Fi и Bluetooth (AIC8800D80
вместо RK915), наличием контроллера Type-C HUSB311 и тем, что роль USB
определяется только через `usb-role-switch`.

Описание самого дистрибутива, список устройств и эмуляторов, условия лицензии —
в [README апстрима](README-upstream.md) рядом с этим файлом. Всё, что там
написано, остаётся в силе; ниже только наши отличия.

## Зачем этот форк

Официальный образ AURKNIX на этой плате не запускается: экран остаётся чёрным с
самого старта ядра. Причина — выход RGB ждёт мост RK628, которого на плате нет,
и утягивает за собой исправную панель DSI. Кроме того, образ по умолчанию
грузится деревом устройства от ревизии A, так что владельцу ревизии B нужно
сначала вручную запустить `dtbselect` — а без экрана это сделать нечем.

Здесь обе проблемы решены, а заодно подключён доработанный загрузчик, который
показывает заставку и анимацию зарядки.

## Чем отличается от апстрима

| | |
|---|---|
| дерево по умолчанию | ревизии B, `dtbselect` вручную запускать не нужно |
| дисплей | молчащий мост RK628 больше не роняет DRM целиком |
| загрузчик | [mamaich/u-boot-rk3562-rg52mini](https://github.com/mamaich/u-boot-rk3562-rg52mini) вместо вендорского: заставка, анимация зарядки, светодиод при включении, выключение кнопкой, консоль на `uart0` |
| Bluetooth | AIC8800 по SDIO, собирается с `CONFIG_SDIO_BT` |
| USB | фильтр ложного babble в dwc3 — плохой кабель больше не отключает корневой порт |
| звук | убран щелчок динамика, исправлена частота АЦП кодека RK817 |

Подробности каждой правки и то, как они проверялись, — в документации ниже.

## Где что лежит

Правки ядра и загрузчика живут не здесь, а в отдельных форках: они нужны и
другим сборкам для этого устройства, а не только этой.

| | |
|---|---|
| [mamaich/kernel_rk3562](https://github.com/mamaich/kernel_rk3562) | ядро; ветка `aurknix-rg52mini` — база AURKNIX с нашими правками, ветка `master` — дерево dArkOS |
| [mamaich/u-boot-rk3562-rg52mini](https://github.com/mamaich/u-boot-rk3562-rg52mini) | загрузчик, готовые образы в разделе Releases |
| этот репозиторий | образ, дерево устройства, настройки сборки |

## История выпусков

### [rg52mini-20260920](../../releases/tag/rg52mini-20260920) — 20.09.2026

Первый выпуск. Проверен на устройстве: система загружается, экран работает,
USB host работает.

Образ **предварительно настроен на RG52 Mini ревизии B** — запускать
`dtbselect` вручную не нужно. Для других устройств и для ревизии A выбор
дерева по-прежнему за владельцем: `/flash/dtbselect` на устройстве или
приложенный к выпуску `DtbselectWin64.exe`.

Относительно официальной сборки AURKNIX: дисплей поднимается на платах без
моста RK628, наш загрузчик с заставкой и анимацией зарядки, Bluetooth на
AIC8800 по SDIO, фильтр ложного babble в dwc3, убран щелчок динамика,
ограничение напряжения выше 95 °C, включена диагностика через pstore.
