Первый выпуск нашего форка. Собран из ветки `next`, коммит `16a5155c`.
Проверен на устройстве: система загружается, экран работает, USB host работает.

## Для кого этот образ

**Предварительно настроен на AISLPC RG52 Mini ревизии B** — той, где Wi-Fi и
Bluetooth на AIC8800D80, а роль USB определяет контроллер Type-C HUSB311.
Записали на карту, включили — ничего выбирать не нужно.

Образ единый и годится также для RG43H Pro и RG43V Pro. **Для любого другого
устройства, а также для ревизии A**, дерево устройства по-прежнему нужно
выбрать вручную: запустите `/flash/dtbselect` на самом устройстве или
`DtbselectWin64.exe` с загрузочного раздела на компьютере.

* записи **без суффикса** — Wi-Fi AIC8800 (ревизия B);
* записи с **`v1`** — RG52 Mini v1, RG43H Pro v1, RG43V Pro v1 — Wi-Fi RK915
  (ревизия A).

`DtbselectWin64.exe` приложен к выпуску отдельным файлом: в самом образе его
нет, положите его в корень загрузочного раздела. Версия для устройства
(`dtbselect`) на разделе уже лежит.

## Чем отличается от официальной сборки AURKNIX

| | |
|---|---|
| дерево устройства | ревизии B по умолчанию — `dtbselect` вручную запускать не нужно |
| дисплей | молчащий мост RK628 больше не роняет DRM целиком; на платах без него экран больше не чёрный |
| загрузчик | наш вместо вендорского: заставка при включении, анимация зарядки, светодиод сразу после подачи питания, выключение кнопкой, консоль на `uart0` 1500000 |
| Bluetooth | AIC8800 по SDIO через BlueZ (в официальной сборке выключен) |
| USB | фильтр ложного babble в dwc3 — плохой кабель больше не отключает корневой порт |
| звук | убран щелчок динамика при старте и остановке воспроизведения, исправлена частота АЦП кодека RK817 |
| термика | ограничение напряжения выше 95 °C |
| диагностика | pstore и детекторы зависаний включены, `DEBUG_CREDENTIALS` выключен |

Ядро — [mamaich/kernel_rk3562](https://github.com/mamaich/kernel_rk3562), ветка
`aurknix-rg52mini`. Загрузчик —
[mamaich/u-boot-rk3562-rg52mini](https://github.com/mamaich/u-boot-rk3562-rg52mini),
выпуск `rg52mini-1.1`.
